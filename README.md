# 佛萊明左右手定則 3D 教學檢視器

線上使用（無需安裝）：[https://tai-sura.github.io/PHY-Fleming-s-hands-rule/](https://tai-sura.github.io/PHY-Fleming-s-hands-rule/)

把 V20 的左右分屏模型檢視器，升級為 Vite + TypeScript + three.js 的互動教學應用：可顯示／隱藏 F、B、I 向量、套用自然膚色、左右獨立或同步旋轉，並附有公式教具。GitHub Pages 由倉庫根目錄提供正式建置（`index.html`、`assets/`、`models/`）。`docs/` 是同一份建置備份。本機若要用 Vite 開發，請先把 `index.dev.html` 複製為開發用入口。

- **左半屏**：佛萊明左手定則（摩打）　公式 \(F = B I L \sin\theta\)
- **右半屏**：佛萊明右手定則（發電機）　公式 \(E = B \ell v \sin\theta\)

預設埠號：`4178`（與直流摩打預覽的 `4177` 並排使用）。

## 啟動

```bash
cd fleming-hands
npm install
npm run dev
```

瀏覽器打開終端顯示的位址（預設 `http://127.0.0.1:4178/`）。

正式建置：

```bash
npm run build
npm run preview
```

重新優化原始 GLB（可選）：

```bash
npm run optimize
```

## 操作說明

| 操作 | 說明 |
| --- | --- |
| 拖曳／滾輪 | 旋轉視角、縮放 |
| **開始／停止旋轉** | 各半屏可獨立自動旋轉 |
| **同步旋轉** | 左右共用同一視角與旋轉狀態 |
| **F／B／I 按鈕** | 顯示或隱藏對應的字母與箭頭 |
| **自然膚色／膚色強度** | 在掃描灰白質感上疊加暖色膚調，可還原原色 |
| **顯示公式向量** | 在模型旁邊顯示可隨 θ 變化的公式向量組；方向同對應手指一致（右手 v 為藍、E 為紅，跟手勢顏色相同） |
| **公式教具滑桿** | 調整 B、I 或 v、長度與夾角 θ，即時計算 F 或 E |
| **開啟預設…** | 重新載入優化後的預設模型 |
| **正面／側面／頂視／背面** | 鏡頭跳到該側手勢的預設視角（正面即原本斜視教學角） |
| **繞 F／B／I 軸 ±15°／±90°** | 只轉模型、唔轉鏡頭，沿當前手指方向旋轉 |
| **對齊：朝鏡頭／垂直／水平** | 把指定的 F、B 或 I 對準鏡頭、螢幕向上或向右 |
| **重設視角** | 只還原鏡頭，唔改模型旋轉 |
| **重設模型旋轉** | 只還原手勢朝向，唔改鏡頭 |
| **0°／90°／180°** | 把公式夾角 θ 設成常用值 |

## 手指對應（DSE 佛萊明定則）

手勢同你提供的 GLB 一致，映射為標準約定：

- 拇指（藍色 **F**）：左手為力的方向；右手模型仍標為 F，對應發電機的運動方向 \(v\)
- 食指（綠色 **B**）：磁場方向
- 中指（紅色 **I**）：電流（左手）或感應電流／電動勢方向（右手）

θ 是電流（或運動）方向同磁場 B 之間的夾角，不是手指關節角。手勢保持三指垂直；大小由 \(\sin\theta\) 決定。3D 公式向量組同下方 2D 示意圖都對齊手勢方向：90° 時同三隻手指平行，θ 變化時 I 或 v 在 B 與該方向構成的平面內轉動。

## GLB 優化摘要

原始模型由 Microsoft GLTF Exporter 輸出，同時帶有金屬粗糙與鏡面光澤貼圖，大量 2048×2048 PNG，金屬度還被設成 1，檔案各約 57–60 MB。優化流程會：

1. 為 `letter-F/B/I`、`arrow-F/B/I`、`hand` 節點命名，方便教學開關
2. 轉成標準金屬粗糙工作流，金屬度改為 0（介電質／皮膚）
3. 純色字母與箭頭改為顏色係數，不再使用 8×8 貼圖
4. 去掉完全不透明的多餘 Alpha，以及未引用的鏡面貼圖
5. 手部反照率縮至 1024 並以 JPEG 壓縮
6. 把模型底部對齊原點，方便投射接觸陰影

詳細數字見 `evidence/optimization-report.md`。
